# Примитивная база данных

Учебный проект на Python — консольное приложение для работы с простой базой данных.

На текущем этапе реализовано управление таблицами: создание, просмотр списка и удаление. Структура таблиц сохраняется в JSON-файле, поэтому метаданные сохраняются между запусками программы.

## Технологии

- Python 3.12+
- uv — управление окружением, зависимостями и сборкой пакета.
- prompt — интерактивный ввод команд.
- Ruff — проверка качества Python-кода.
- JSON — хранение метаданных таблиц.

## Управление таблицами

Программа поддерживает следующие команды:

| Команда | Описание |
|---|---|
| `create_table <имя> <столбец:тип> ...` | Создать таблицу |
| `list_tables` | Показать список таблиц |
| `drop_table <имя>` | Удалить таблицу |
| `help` | Показать справку |
| `exit` | Завершить программу |

Поддерживаемые типы столбцов: `int`, `str`, `bool`.

При создании таблицы автоматически добавляется столбец `ID:int`, если он не указан пользователем.

### Пример использования

```text
>>>Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool

>>>Введите команду: list_tables
- users

>>>Введите команду: create_table users name:str
Ошибка: Таблица "users" уже существует.

>>>Введите команду: drop_table users
Таблица "users" успешно удалена.

>>>Введите команду: list_tables
Таблиц пока нет.

>>>Введите команду: exit
```

## Хранение метаданных

Информация о таблицах сохраняется в файле `db_meta.json` в корне проекта.

Пример:

```json
{
    "users": [
        "ID:int",
        "name:str",
        "age:int",
        "is_active:bool"
    ]
}
```

Файл `db_meta.json` исключён из Git с помощью `.gitignore`.

На данном этапе приложение хранит только структуру таблиц. Операции с записями будут реализованы в следующих этапах проекта.

## Структура проекта

```text
src/
└── primitive_db/
    ├── __init__.py
    ├── core.py
    ├── engine.py
    ├── main.py
    └── utils.py
```

- `main.py` — точка входа.
- `engine.py` — командный цикл и обработка пользовательского ввода.
- `core.py` — создание и удаление таблиц.
- `utils.py` — загрузка и сохранение JSON.
