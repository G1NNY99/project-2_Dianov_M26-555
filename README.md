
# Примитивная база данных

Учебный проект на Python — консольное приложение для работы с простой базой данных.

Программа позволяет создавать и удалять таблицы, добавлять, просматривать, изменять и удалять записи. Структура таблиц и их данные сохраняются в JSON-файлах между запусками приложения.

Для повышения надёжности используются декораторы обработки ошибок, подтверждения опасных операций и измерения времени. Повторные запросы `select` ускоряются с помощью кэширования на основе замыкания.

## Технологии

- Python 3.12+
- uv — управление окружением, зависимостями и сборкой пакета.
- prompt — интерактивный ввод команд.
- PrettyTable — вывод записей в виде таблиц.
- Ruff — проверка качества Python-кода.
- JSON — хранение метаданных и записей.
- Декораторы Python — обработка ошибок, подтверждение действий и измерение времени.
- Замыкания Python — кэширование результатов запросов.

## Управление таблицами

| Команда | Описание |
|---|---|
| `create_table <имя> <столбец:тип> ...` | Создать таблицу |
| `list_tables` | Показать список таблиц |
| `drop_table <имя>` | Удалить таблицу и её данные |
| `help` | Показать справку |
| `exit` | Завершить программу |

Поддерживаемые типы столбцов: `int`, `str`, `bool`.

При создании таблицы автоматически добавляется столбец `ID:int`. Пользователю не нужно указывать его значение.

Пример:

```text
>>>Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool

>>>Введите команду: list_tables
- users
```

Удаление таблицы требует подтверждения. При ответе `n` операция отменяется.

## CRUD-операции

CRUD — четыре базовые операции над данными: Create, Read, Update, Delete.

| Операция | Команда | Назначение |
|---|---|---|
| Create | `insert into <таблица> values (<значения>)` | Добавить запись |
| Read | `select from <таблица>` | Показать все записи |
| Read | `select from <таблица> where <условие>` | Найти записи по условию |
| Update | `update <таблица> set <поле> = <значение> where <условие>` | Изменить записи |
| Delete | `delete from <таблица> where <условие>` | Удалить записи |

Дополнительная команда `info <таблица>` показывает структуру таблицы и количество записей.

### Добавление записи

```text
>>>Введите команду: insert into users values ("Sergei", 28, true)
Запись с ID=1 успешно добавлена в таблицу "users".
Функция insert выполнилась за 0.000 секунд
```

Значение `ID` генерируется автоматически. Все остальные поля обязательны, а их значения должны соответствовать типам столбцов.

Строковые значения заключаются в кавычки, целые числа записываются без кавычек, логические значения указываются как `true` или `false`.

Время выполнения операции измеряется автоматически. Значение в секундах может отличаться.

### Чтение записей

```text
>>>Введите команду: select from users
Функция select выполнилась за 0.000 секунд
+----+--------+-----+-----------+
| ID |  name  | age | is_active |
+----+--------+-----+-----------+
| 1  | Sergei |  28 |    True   |
+----+--------+-----+-----------+
```

Чтение с условием:

```text
>>>Введите команду: select from users where age = 28
Функция select выполнилась за 0.000 секунд
+----+--------+-----+-----------+
| ID |  name  | age | is_active |
+----+--------+-----+-----------+
| 1  | Sergei |  28 |    True   |
+----+--------+-----+-----------+
```

При повторном одинаковом запросе результат может быть получен из кэша. В таком случае функция `select()` повторно не вызывается и сообщение о времени выполнения не появляется.

### Изменение записи

```text
>>>Введите команду: update users set age = 29 where ID = 1
Функция select выполнилась за 0.000 секунд
Запись с ID=1 в таблице "users" успешно обновлена.
```

Изменять столбец `ID` запрещено.

После успешного изменения записи кэш запросов очищается.

### Удаление записи

Удаление записи требует подтверждения:

```text
>>>Введите команду: delete from users where ID = 1
Функция select выполнилась за 0.000 секунд
Вы уверены, что хотите выполнить "удаление записей"? [y/n]: y
Запись с ID=1 успешно удалена из таблицы "users".
```

При ответе `n` запись сохраняется.

После успешного удаления кэш запросов очищается.

## Декораторы и замыкания

Для улучшения надёжности и устранения повторяющегося кода создан модуль `decorators.py`.

Он содержит три декоратора и функцию создания кэша.

### Обработка ошибок — handle_db_errors

Декоратор `@handle_db_errors` централизует обработку исключений, возникающих при работе с базой данных.

Обрабатываемые исключения:

- `FileNotFoundError` — файл данных не найден.
- `KeyError` — таблица или столбец не найдены.
- `ValueError` — ошибка валидации данных.

Вместо необработанного исключения пользователь получает понятное сообщение об ошибке.

Декоратор применяется к функциям управления таблицами и CRUD-операциям в `core.py`.

### Подтверждение действий — confirm_action

Декоратор `@confirm_action(action_name)` запрашивает подтверждение перед выполнением опасной операции.

Он применяется к функциям:

- `drop_table` — удаление таблицы.
- `delete` — удаление записей.

Пример отмены:

```text
>>>Введите команду: drop_table users
Вы уверены, что хотите выполнить "удаление таблицы"? [y/n]: n
Операция отменена.
```

Если пользователь вводит `y`, операция выполняется. При любом другом ответе она отменяется.

Это помогает предотвратить случайное удаление данных.

### Измерение времени — log_time

Декоратор `@log_time` измеряет продолжительность выполнения функции с помощью `time.monotonic()`.

Он применяется к функциям `insert` и `select`.

Формат сообщения:

```text
Функция select выполнилась за 0.000 секунд
```

Время отображается с точностью до трёх знаков после запятой.

### Кэширование запросов — create_cacher

Функция `create_cacher()` создаёт замыкание для хранения результатов запросов.

Внутренняя функция `cache_result(key, value_func)` использует словарь, сохранённый в замыкании.

Принцип работы:

1. При первом запросе вычисляется результат и сохраняется в кэше.
2. При повторном запросе с тем же ключом возвращается сохранённый результат.
3. Если запрос отличается, результат вычисляется отдельно.
4. После успешного изменения данных кэш очищается.

Ключ кэша учитывает имя таблицы и условие `where`.

Кэш действует в пределах одного запуска приложения. После завершения программы его содержимое не сохраняется.

Пример первого запроса:

```text
>>>Введите команду: select from users
Функция select выполнилась за 0.000 секунд
+----+--------+-----+-----------+
| ID |  name  | age | is_active |
+----+--------+-----+-----------+
| 1  | Sergei |  28 |    True   |
+----+--------+-----+-----------+
```

Пример повторного запроса без изменения данных:

```text
>>>Введите команду: select from users
+----+--------+-----+-----------+
| ID |  name  | age | is_active |
+----+--------+-----+-----------+
| 1  | Sergei |  28 |    True   |
+----+--------+-----+-----------+
```

При повторном запросе строка с временем выполнения отсутствует, поскольку результат взят из кэша.

После успешных операций `insert`, `update`, `delete`, а также создания или удаления таблицы кэш сбрасывается, чтобы последующие запросы возвращали актуальные данные.

## Хранение данных

Метаданные таблиц хранятся в файле `db_meta.json` в корне проекта.

Пример метаданных:

```json
{
    "users": [
        "ID:int",
        "name:str",
        "age:int",
        "is_active:bool"
    ]
}
```

Записи каждой таблицы сохраняются отдельно в каталоге `data/`.

Например, файл `data/users.json` может содержать:

```json
[
    {
        "ID": 1,
        "name": "Sergei",
        "age": 28,
        "is_active": true
    }
]
```

При удалении таблицы её JSON-файл с записями также удаляется.

Файлы данных и метаданных исключены из Git с помощью `.gitignore`.

## Структура проекта

```text
src/
└── primitive_db/
    ├── __init__.py
    ├── core.py
    ├── decorators.py
    ├── engine.py
    ├── main.py
    ├── parser.py
    └── utils.py
```

- `main.py` — точка входа.
- `engine.py` — обработка команд, интерактивный цикл и кэширование запросов.
- `core.py` — управление таблицами и CRUD-операции.
- `decorators.py` — обработка ошибок, подтверждение действий, измерение времени и замыкание для кэширования.
- `parser.py` — разбор пользовательских значений и условий.
- `utils.py` — загрузка и сохранение JSON, удаление файлов таблиц.
